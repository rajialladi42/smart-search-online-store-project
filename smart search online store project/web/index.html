Academic Architecture & Subject Integration

2nd-Year B.Tech Mini-Project: ADSA + DMGT + OOPJ + Python AI

AVL Self-Balancing Binary Search Tree

• Guarantee: Every node maintains a Balance Factor \(BF = \text{height}(L) - \text{height}(R) \in \{-1, 0, 1\}\).

• Rotations Implemented: LL (Single Right), RR (Single Left), LR (Double Left-Right), RL (Double Right-Left).

• Search & Autocomplete Complexity: Time complexity is strictly bounded by \(\mathcal{O}(\log N + k)\) where \(k\) is the number of prefix matches, preventing \(\mathcal{O}(N)\) tree degradation.

Current Catalog Size: 52 items | AVL Tree Height: 6 levels | Max theoretical search steps: 6 comparisons

Discrete Mathematics: Set Algebra Filtering

• Universe of Discourse: \(U = \{p_1, p_2, \dots, p_N\}\) representing all 52 catalog items.

• Facet Sets:

  • \(S_{\text{brand}} = \{x \in U \mid x.\text{brand} \in B\}\)
  • \(S_{\text{category}} = \{x \in U \mid x.\text{category} \in C\}\)
  • \(S_{\text{price}} = \{x \in U \mid P_{\min} \le x.\text{price} \le P_{\max}\}\)
  • \(S_{\text{rating}} = \{x \in U \mid x.\text{rating} \ge R_{\min}\}\)

• Filter Equation: \(S_{\text{result}} = S_{\text{search}} \cap S_{\text{brand}} \cap S_{\text{category}} \cap S_{\text{price}} \cap S_{\text{rating}}\).

NLP Content-Based Filtering (TF-IDF & Cosine Similarity)

• TF-IDF Vectorization:

$$\text{TF-IDF}(t, d) = \left(1 + \ln \text{TF}(t, d)\right) \times \left(\ln\frac{1 + |D|}{1 + \text{DF}(t)} + 1\right)$$

• Cosine Similarity Metric: Computes angular distance between high-dimensional normalized feature vectors:

$$\text{Similarity}(A, B) = \frac{A \cdot B}{\|A\|_2 \|B\|_2} = \sum_{i=1}^V A_i B_i$$

• Recommendations: When viewing e.g. Sony WH-1000XM5, the engine calculates cosine similarity against all other items to return top 4 matching products.

Object-Oriented Programming in Java

• Encapsulation: Private attributes in Product, AVLNode, and Catalog with immutable accessors.

• Layered Architecture: Separation between Data (Product), Index (AVLTree), Filter (SetFilterEngine), and Controller (SearchEngine).

• Type Generics: Generic mathematical set operators \(\langle T \rangle\) in SetFilterEngine.
